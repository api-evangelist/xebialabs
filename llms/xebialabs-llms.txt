# XebiaLabs

> XebiaLabs was an enterprise DevOps software company behind XL Deploy (deployment automation), XL Release (release orchestration), and XL Impact. In February 2020 it merged with CollabNet VersionOne to form Digital.ai; xebialabs.com now redirects to digital.ai, and the products live on as Digital.ai Deploy and Digital.ai Release. The XebiaLabs GitHub organizations, package registries, and the dist.xebialabs.com distribution site remain live, and the xl CLI is still released there on the current Digital.ai version train.
